# 全周期员工服务

员工在 `http://localhost:5174/` 对话办理，左侧「我的服务单」查询状态、补充说明、上传 PDF 材料和下载交付文件。
HR 在工作台「HRSSC 服务办理」处理申请，并可按姓名、工号选择员工发布工资明细。

支持的发起语句：

- 我要办理入职材料核验 / 我要咨询合同签署
- 我要申请请假 / 查询我的 2026-08 工资条
- 我要办理人事变更 / 我要咨询社保公积金
- 我要申请离职 / 查看交接清单 / 我要核对离职结算
- 补发离职证明 / 我要调取档案 / 我要申请劳动关系证明

逐项填写后回复「确认提交」，申请才进入人工队列。「取消办理」取消草稿；「查看我的服务申请」查询进度。
合同咨询等字段支持直接填写完整问题。日期支持完整日期及今天、明天、后天。

请假复用原有额度校验、主管审批、HR 备案和扣减逻辑。其他事项由 HR 审核后实际办理，再写入办结说明；系统不会因一张服务单审核通过就自动更改劳动关系、银行账户或员工档案。
证明类服务单需要 HR 上传已核验的 PDF 后才能办结。申请材料和交付文件均在本系统加密保存，不交给外部模型解析。
工资数据必须由 HR 发布，未发布时明确提示无数据，不生成示例金额。每个员工只能查询自己的工资和服务记录。
离职申请审核通过后，未来 30 天内的计划日期进入既有交接提醒和日历，办结后提醒撤除。

离职后登录要求平台账号有效，且原企业成员和员工档案仍绑定该账号；档案状态为 LEFT 时只开放生命周期服务，不恢复在职业务权限。注销或解除身份关联的账号不能通过此入口恢复访问。

校验脚本：`scripts/test-lifecycle.cjs`、`scripts/test-lifecycle-materials.cjs`；后端测试涵盖审批状态、重复确认、本人/租户隔离、材料访问、工资月份和离职交接提醒。
浏览器测试使用演示账号生成标记明确的验收服务单，不修改真实员工档案，也不发布模拟工资。
