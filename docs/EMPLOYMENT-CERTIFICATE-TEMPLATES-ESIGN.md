# 在职证明模板与腾讯电子签

## 员工办理流程

1. 在 Agent AI 中说“我要开在职证明”，填写用途、语言、薪资展示及补充要求。
2. 系统询问是否使用自己提供的模板。选择“公司模板”或“自行上传”。
3. 自备模板可通过对话框附件或消息中的上传入口提交，格式为 DOCX，大小不超过 5 MB。
4. 系统识别字段，姓名、部门、职位、入职日期等从员工档案和本次申请中填入；接收单位等自定义字段由员工补充确认。
5. 员工确认提交后，HR 核对申请、档案、原始模板和补充字段，审核通过后生成证明。
6. 系统将生成的证明送入腾讯电子签，转换为 PDF、发起公司盖章并查询结果。
7. 腾讯电子签返回签署完成后，员工可在“我的服务单”或证明申请详情中下载已盖章 PDF。

## 两种模板

- 公司模板：HR 在“在职证明 → 公司模板”维护。通用证明的国家和受理机构填写“通用”；签证模板填写对应国家和受理机构。按语言及用途信息匹配最新启用模板，也可在申请页选择具体模板。
- 个人模板：只供上传人和本企业 HR 查看，与对应申请一起审核。审核通过后仍属于个人模板。

未配置通用中文公司模板时，使用系统内置的中文在职证明或收入证明格式。

支持字段示例：`{{legalName}}`、`【姓名】`、`${公司名称}`、`职位：____`，以及表格中“入职日期”旁的空白单元格。支持正文、表格、页眉页脚和跨字体片段的字段。自定义字段可以写为 `【接收单位】`。

系统保留上传的原始文件，生成时替换字段并保留原有段落和文字样式。生成文件会保留或补充“公司盖章处”，用于电子印章定位。

## HR 电子签设置

进入“在职证明 → 腾讯电子签”，填写企业名称、经办人 UserId、印章 SealId、腾讯云 SecretId 和 SecretKey，并启用“审核通过后自动盖章”。企业账号需完成腾讯电子签自动签署开通，以及经办人、应用和电子印章的权限配置。

密钥在服务端加密保存。页面再次打开时只显示已保存状态，密钥输入框留空可保留原配置。每份签章任务保存对应配置快照，后续修改设置不会改变已发起的任务。

默认定位文字为“公司盖章处”。使用其他定位文字时，应确保生成的模板中存在且仅存在一处该文字。

尚未设置电子签时，已生成的证明显示等待配置。完成设置后，HR 可在申请详情中点击“发起电子签章”。

## 状态及处理

- 准备签章文件：上传 DOCX、创建转换任务并等待 PDF 转换完成。
- 电子签章处理中：腾讯电子签已受理流程，系统持续查询签署结果。
- 电子签章已完成：腾讯 `FlowStatus=4`，开放已盖章 PDF 下载。`FlowStatus=2` 是部分签署，继续等待。
- 签章处理失败：显示错误信息；尚未创建腾讯流程的任务可由 HR 处理配置后重新发起。
- 待核对腾讯签章结果：创建流程时遇到网络中断或结果不明确，系统停止重复发起。HR 在腾讯电子签按 `HR在职证明-企业ID-申请ID` 查找对应流程并填写流程 ID，系统校验证明编号和经办人后恢复查询。

Word 原稿和腾讯已盖章 PDF 分别提供下载。已盖章 PDF 由服务端取得腾讯文件并返回，腾讯临时下载地址不暴露给前端。

## 接口实现

采用腾讯自建应用 API，服务端使用 TC3-HMAC-SHA256 签名。

处理顺序：`UploadFiles` → `CreateFileConvertTask` → `DescribeFileConvertTask` → `CreateFlowByFiles` → `DescribeFlowBriefs` → `DescribeFileUrls`。

公司盖章使用企业自动签署 `ApproverType=3`、`SIGN_SEAL` 控件和关键词定位。HR 审核与签章任务入库在同一事务中完成，外部电子签调用由后台任务执行。数据库版本和任务抢占避免并发重复执行，流程创建结果不明确时保留人工核对入口。

参考：[腾讯电子签 API](https://qian.tencent.com/developers/companyApis/)、[自动签署说明](https://qian.tencent.com/developers/company/autosign_guide/)、[查询签署流程](https://qian.tencent.com/developers/companyApis/queryFlows/DescribeFlowBriefs/)。

## 验证方式

后端测试覆盖字段识别、真实文档生成、原始文件保留、个人模板隔离、对话字段确认、重复提交保护、腾讯任务转换、签署状态判断、并发抢占及网络中断处理。

浏览器回归脚本为 `scripts/test-certificate-flow.cjs`，使用真实构建页面和隔离的合成接口数据验证两个上传入口、字段填写、申请提交、HR 电子签设置及盖章 PDF 下载。

腾讯云调用在自动测试中使用模拟响应；企业账号配置后的真实盖章联调通过对应证明申请完成。
