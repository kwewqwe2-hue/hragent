# 自然对话与政策重点

助手侧栏保留新对话、我的服务单、前往工作台，移除服务目录与知识图谱快捷按钮。

政策宽泛问题先给主题选择并询问一个关键问题；具体问题优先采用完整、已维护的问答要点。针对年假有效期提取完整的期限句，不显示无关工龄档位。条件、适用性未确认和版本冲突仍保留提示，完整依据通过响应 `details` 字段供前端按需展开。要求原文时直接返回完整内容。

简短追问仅在同企业、同员工、同对话下匹配已知主题。主题缓存 15 分钟，不保存原始员工消息，服务重启后清空。此功能是有限主题引导，不等于完整长期对话记忆。

日常问候、办理开场和模型提示使用自然语气；情绪关怀、安全支持、个人业务结果不经过政策精简器。提交仍需确认，历史服务单查询按钮可直接打开，只读导航不受最新消息限制。
