# 工作沟通与情绪支持

2026-09-08 修复“怎么和主管进行沟通相关的工作安排？”被工时和交通报销条款抢答的问题。网页Agent AI、关怀咨询表单和制度问答入口均在安全支持之后、制度检索之前识别工作沟通和情绪支持意图。

覆盖主管沟通、工作量与取舍、时间安排、沟通被拒绝、同事冲突、受到批评、新人适应、疲惫倦怠、睡眠困扰、情绪整理、先倾听及积极心情分享。回应按情境选择可行步骤、表达示例和一个必要问题；倾诉请求不强推方案，普通沟通和积极情绪不自动转介心理咨询。明确询问政策、金额和审批权限时继续使用制度知识。混合倾诉优先提供支持。

本地服务无需模型Key即可覆盖上述常见情境，不把这些消息提交到通用模型、制度检索或组织统计；不诊断疾病、不推断同事恶意。紧急安全风险及现存人工工单继续优先走原有安全支持，配置了EAP时仅在适当情境提供实际渠道，不编造预约或已经有人接管。更广泛的自由对话仍依赖原有模型配置。当前关怀表单按本次输入回复，并未新增跨轮心理档案或对话记忆。

压力支持的一般原则参考[WHO压力应对指南介绍](https://www.who.int/publications-detail-redirect/9789240003927)和[WHO心理支持平台](https://www.emro.who.int/mhps/dealing_with_stress.html)，于2026-09-08核验；产品中的回应为独立编写的建议，不是WHO诊断、量表或官方治疗服务。

测试覆盖场景分类、具体回应、倾听偏好、政策不误拦截、危机优先及不做诊断。实际验收使用截图原问题及另12个情境，在Agent AI和制度入口均得到一致的支持回答；关怀页面桌面与手机验收通过，原有26个制度问题与Agent AI一致性回归通过。脚本为 `scripts/test-workplace-support.cjs`，结果保存在 `.artifacts/workplace-support`。
