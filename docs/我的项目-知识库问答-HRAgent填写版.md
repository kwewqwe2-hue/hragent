# 我的项目 · 知识库问答

项目名称：HRAgent 员工关系智能助手  
业务场景：员工制度咨询与请假前信息核对

## 知识库问答怎么写

### 问题与范围

我的项目：

员工问题：“请假要通过什么渠道申请，需要先完成哪些手续？”

查询日期：2026-09-09；角色：员工；查询范围：当前登录企业知识库内的请假制度。

本例按《职工工时及休假实施办法》适用范围设置查询对象：与上海临港漕河泾人才有限公司依法建立劳动关系，且不属于退休返聘、实习见习、劳务派遣、聘用及外包等排除范围的职工。系统根据员工所属企业、合同主体和用工身份匹配制度。

本次输出请假渠道、手续和审批要求。员工进一步询问本人余额或申请进度时，调用本人业务台账并单独标注数据来源。

### 检索依据

我的项目：

资料名称：《职工工时及休假实施办法》。文件编号：CHR-RS-17；版本：A0；封面实施日期：2025-10-14。

适用范围依据为 **PDF第2页第二条**：

> 本办法适用于与公司依法建立劳动关系的职工（不包括退休返聘、实习见习、劳务派遣、聘用及外包人员）。

回答依据为 **PDF第6页第十五条“请假手续”**：

> （一）职工应当通过公司钉钉系统在线提交各类假期申请，经所在部门负责人或分管领导批准同意后准予休假。
>
> （二）职工应当配合提供符合公司管理要求的相关休假证明材料。
>
> （三）除特殊情况外，职工应事先履行并完成请假手续后方可休假。

解释部门依据为 **PDF第6页第十九条**：“本办法由公司行政人事中心负责解释。”

检索按“企业范围 → 适用人员 → 审核状态与版本 → 问题相关条款”筛选，返回原文片段和来源定位。第十五条作为请假手续的直接依据，具体假种的特殊要求继续匹配对应专项条款。

### 答案

我的项目：

你需要先通过公司钉钉系统在线提交请假申请，配合提供符合公司要求的休假证明材料，经所在部门负责人或分管领导批准后休假。除特殊情况外，应在休假前完成请假手续。

依据：《职工工时及休假实施办法》CHR-RS-17 A0，第十五条，PDF第6页，实施日期2025-10-14。

下一步：确定要申请的假种和日期，进入钉钉请假入口；如需了解具体材料，继续查询该假种对应条款或联系行政人事中心。

### 证据不足

我的项目：

- **询问具体假种需提供哪些证明**：继续检索对应假种条款；缺少明确清单时回答“请告诉我具体假种，我会查找对应材料要求；需补充的材料由行政人事中心确认”。
- **询问“我的申请一定会批准吗”**：回答“请提交申请，由所在部门负责人或分管领导根据具体情况审批”。
- **询问“我还剩多少年假”**：读取本人假期余额接口，返回余额和查询依据；无台账时提示“请HR核对并补充你的假期台账”。
- **员工适用信息缺失**：列出需要补充的合同主体或用工身份，交HR核对后匹配适用制度。
- **同一事项出现版本冲突**：保留两份制度的名称、版本、条款和差异，交行政人事中心确认适用版本。

知识缺口汇总为HR知识待办，由HR补充条款、材料清单或适用信息，再更新对应问答。

### 更新责任

我的项目：

制度解释与内容维护由 **行政人事中心／企业HR负责人** 负责；知识库导入、索引更新和测试由 **项目开发／测试负责人** 负责。

维护安排为：HR每周检查一次制度修订和知识待办；遇到制度新发、修订、废止、审批流程调整或员工反馈答案有误时，及时核对原文并更新。

新版本入库时维护文件编号、版本、实施日期、适用范围及修订关系。HR明确替代关系后，标记被替代旧版的状态，保留历史原文与引用；按地区或人员范围并行适用的版本分别维护。

更新后复测请假渠道、材料要求、审批角色、适用范围和证据不足等问题，并检查答案、版本与页码是否对应。维护记录保留更新人、时间、变更原因和复测结果。
