# 官方政策监测

后台 `OfficialPolicyCrawler` 在服务启动后补查一次，并每天北京时间 08:00、18:00 执行。服务器和网络须持续运行；关闭期间不会检查。`app.policy-crawler.enabled` 可禁用定时检查，`app.policy-crawler.cron` 可配置计划（默认 `0 0 8,18 * * *`）。单实例执行，内存互斥防重复；多实例部署前需改为分布式锁。

HR 在「知识库 → 政策更新与维护」查看来源健康状态、立即检查、核验候选。接口 GET `/admin/policy-monitor/sources`、POST `/admin/policy-monitor/scan` 仅 HR 可用。

来源为上海人社规范性文件、北京人社政策文件、人力资源社会保障部政策文件、中国政府网部门文件。每个来源抓取栏目首页最多 20 篇相关 HTML 文件，轮询复查最多 20 篇已采集文件。遵守 robots.txt，仅 HTTPS 同主机，不跟随重定向；请求超时、网页变更、超长正文、附件未解析等明确记录失败，不能推断无更新。不覆盖全网、所有地区及历史库。需要其他地区时应配置相应官方来源和页面适配器。国家法律法规数据库作为人工核验入口，未声称已绕过其访问限制完成自动抓取。

知识库下方的 Kaka 气泡每 5 秒（页面可见时）读取 `/policy-monitor/progress`，展示本轮来源进度、已处理文件、当前官网和文件名，以及来源失败详情。候选和已入库数量按当前租户统计。历史检查成功时间单独显示；本轮结束不等于全部来源成功，更不等于全部政策已核验。政策保留原始发布/生效日期，不把仍有效的旧年法规改名为“2026 版”。

国家政策图谱按地区→主题→官方文件分层，公司制度图谱按企业业务板块→制度条款展开。企业提供文件优先归公司图谱；官方 HTTPS 域名用于国家/地方来源识别；来源不明确或演示文件进入参考资料。图谱连线只表达导航分类，不推断法律授权或替代关系。

企业年金回应使用 `CompanyBenefitReply`，同时覆盖政策模块和 Agent。HR 在知识库选择“企业福利确认”，标题含“企业年金”，正文单独一行填写 `设立状态：已设立` 或 `设立状态：未设立`，并设置生效日期、适用合同主体和审核状态。仅当前租户、有效且适用的已审核确认能生成确定结论；冲突、过期、无资料均引导核实。没有预置“本公司未设立”的假数据。一般年金解释、国家政策查询及争议/求助不作话题屏蔽。

正文 SHA-256 去重，首次发现即保存租户隔离的待核验候选。官方内容仅本地保存，不发送给第三方索引服务。HR 核实原文、附件、适用地区、生效时间及废止关系后批准，正式入库。同 URL 旧版截止日期设为新版生效日前一天；跨 URL 废止关系必须在知识库人工维护。不同单位、地区或特定人群的适用限制也应由 HR 补充正式文章字段。

助手对相关待核验文件提示需要核实；审核通过且已经生效的文件参与本地检索，并附官方链接和生效日期。员工余额、工资明细等个人查询仍走业务数据。采集与审核不能保证政策永远最新或回答零错误。

验证：OfficialPolicyCrawlerTest、OfficialPolicyIngestServiceTest、OfficialPolicyAnswerTest 及原 PolicyMonitorServiceTest、PolicyCopilotServiceTest。`node scripts/check-policy-monitor.cjs --start` 启动检查并验证员工无权操作；不带参数只读状态。

2026-09-11 后续核验：`scripts/review-verified-policies.cjs` 默认生成可复核清单，带 `--apply` 才通过正常审核接口发布明确选择的十份官方文件。发布前校验租户、文件 URL 和已核验正文哈希，发布后核对生效/截止/原始发布日期；不批量批准未知文件。核验计划及执行记录位于 `.artifacts/policy-review/verified-plan.json` 与 `published-results.json`。内容覆盖上海工资支付、劳动合同、失业保险、工伤费率及特定人群养老待遇，北京2026社保基数、城乡居民养老缴费及就业援助。北京工伤康复通知的页面元数据与落款日期不一致，含未读附件、需关联原文件、仅适用于历史年度的其他候选继续待核验。

审核接口允许填写 `effectiveTo` 与 `publishedAt`，拒绝截止日期早于生效日期。明确问某地区官方政策时，以该地区检索官方文件而不修改员工档案；个人企业政策仍按员工档案匹配。无关主题的待核验文件、同主题的较早版本不再遮挡已经确认的新版本；同文件的更新候选仍触发待核验提示。已过期和未来生效条文不会作为当前执行依据。

受限来源的官方转载可作为人工核验线索；没有将禁止自动采集的转载站加入爬虫。已核对的企业年金转移接续新规（人社厅函〔2026〕89号）在正文第十三条规定自2027-01-01起实施，不能作为2026年的现行办理指引。
