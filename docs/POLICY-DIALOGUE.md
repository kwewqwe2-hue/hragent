# 政策对话引导

“我要休假”“我想休假”“帮我申请休假”直接进入原有请假草稿；不会检索年假全文。查询政策可以暂停填写，工龄等政策追问的答案优先回到政策会话，不写进请假字段。业务切换会清除旧的政策上下文。

年假天数询问先确认累计工龄（包括以前单位），再确认连续工作条件。只解释匹配的完整年度法定基础档位；不把本公司入职时间当累计工龄，也不把基础档位当作当前可用额度。未知工龄、不明确的范围、中断经历等情形不会推测个人权益。员工自述仅保留在企业、员工、会话隔离的短期内存中，15分钟失效，不改动档案或余额。

年假余额和核定额度直接使用真实业务数据，显示总额度、已休、审批占用和可用天数。已有明确工龄时不重复追问。依据采用上海人社公布的《职工带薪年休假条例》（2008-01-01实施）、《企业职工带薪年休假实施办法》（2008-09-18实施）及人社厅函〔2009〕149号，2026-09-10核对：

- https://rsj.sh.gov.cn/tgwyxzfgwj_17255/20200617/t0035_1388259.html
- https://rsj.sh.gov.cn/trlzyhshbzbgz_17256/20200617/t0035_1388390.html
- https://www.mohrss.gov.cn/wap/zc/zcwj/200904/t20090415_91149.html

其他政策正文默认仅保留简短结论或一个必要问题，完整来源和适用说明进入折叠区。住宿按目的地、岗位逐步确认，从已审核企业原文中匹配对应金额；借款按原文金额范围匹配完整审批条件。不能匹配时说明缺口，不凭模型补造金额。明确要求原文时仍可以完整查看依据。
