# 员工服务、关怀与组织运营

入口为原工作台的「员工服务中心 / 员工服务与组织运营」卡片，进入 `/employee-experience` 完整服务页；AI 首页保留现有布局。原有请假、证明、入职审批和员工档案继续使用现有业务数据。新人也可以访问服务与关怀。

## 已接入的流程

- 日常服务：按工作地点、职级、工种、合同主体匹配已审核且有效的制度，展示来源和生效日期；同名有效制度内容不一致时提示 HR 核实。保留证明申请、下载、办事清单和日期提醒。
- 入职与关怀：第一天、第一周、第一个月任务打卡保存到后端；日期来自入职档案。压力支持、企业 EAP 配置及公共求助资源。任务勾选不替代业务审批。
- 离职：交接准备清单、社保与结算核对指引、自愿访谈。不会自动提交离职、停用账号或推断员工已经决定离开。
- 合规：实名或匿名表单收集时间、地点、亲历事实、证据线索、期望帮助；正文与人工回复使用 AES-GCM 加密。指定调查人员接单、回复、结案；员工可补充与查询。这里只提供工单式人工介入，不是实时在线坐席。
- 组织运营：自愿参与的每周去重主题统计，每个部门主题至少 5 人才显示。排除心理与申诉正文；不提供个人离职预测、诊断或风险名单。按周最多保留 8 周的主题信号，每日北京时间 02:15 清理；员工可撤回参与。
- 知识反哺：未匹配制度和「未解决」反馈聚合为主题待办，HR 可标记核实或重新打开；不记录问题原文。

## 必须按企业实际维护的内容

在「组织运营 → 服务配置」填写真实 EAP 名称、电话、预约链接和 ER 联系方式，并指定本企业在职 HR 作为调查人员。未指定时不会接收新敏感申诉，也不会声称已转人工。普通主管和未授权 HR 无法读取工单正文。配置授权与查阅、回复均有审计记录。

在「知识待办」可导入 8 篇服务参考草稿，内容覆盖入职、协作、关怀、离职、申诉、竞业、工伤、调岗调薪。导入幂等，草稿不自动生效。HR 应补全正式制度、适用范围、准确生效日期和内部渠道后审核。现行企业制度缺失时，AI 只提供通用准备建议或说明缺口。

本次通用参考的法规和热线链接分别来自：[国家卫生健康委的热线运行说明](https://www.nhc.gov.cn/xcs/c100122/202512/9731f93a7e0d451284a0da462527cbd2.shtml)、[人社部与最高人民法院典型案例](https://www.mohrss.gov.cn/SYrlzyhshbzb/laodongguanxi_/zcwj/202504/t20250416_540574.html)、[最高人民法院公布的工伤保险条例](https://www.court.gov.cn/shenpan/xiangqing/2182.html)、[上海人社部门提供的劳动合同法](https://rsj.sh.gov.cn/cmsres/89/897868aff05241d4b088ff3db7f1b142/007c2cffa946772c6c52fe4e582c1fe3.pdf)。资料核验日为 2026-09-07；核验日期不是企业政策生效日期，导读不替代结合当地现行规则和事实的专业判断。

## AI 回答顺序与边界

网页和内部工作流接口共用 `EmployeeAgentRouter`：安全与持续人工介入 → 通用服务指引及适用的企业条文 → 实时员工自助服务 → 缺少依据时的手册参考 → 已配置模型/工作流。2022 年手册不再抢先回答已维护的企业制度；参考回答保留出处并注明不等同于现行政策，制度缺口仍进入 HR 待办。

明显的自伤风险、严重情绪或现实劳动争议会优先给出支持提示；已配置调查人员时，建立实名加密支持工单。结案前后续消息追加到工单并暂停自动业务回答。一般科普/预防问题不自动创建申诉。关键词规则不能保证识别所有风险，保留员工主动申诉入口。紧急危险不能等待内部处理；AI 不诊断疾病，也不承诺实时响应。

匿名工单不保存账号关联，32 字节随机查询码只返回一次，数据库仅保存查询码摘要；查询和补充均校验当前企业与查询码。查询码持有人可访问工单，请妥善保管。正文细节、登录与基础设施日志仍可能识别身份，因此不承诺对整个基础设施绝对匿名。已识别并路由到工单的敏感内容不会进入通用 AI 调用记录或 RAG；在浏览器聊天中自行输入的内容仍受原有本地对话历史保存机制影响。

钉钉工作流已加入在模型前执行的 `service-reply` 检查和中文提示词。检查失败时停止自动办理，不把身份或服务错误交给模型猜测。生效需导入更新的工作流并使用有效的内部 Agent Key；不会自动发送任何验收消息到钉钉。网页内置服务无需模型 Key 即可运行，自由模型对话仍需有效模型配置。
