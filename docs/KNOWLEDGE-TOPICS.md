# 知识库主题导航

知识库使用十个政策板块展示已有授权内容，提供知识图谱和分类阅读两种视图。通过工作台的知识库入口访问；助手侧栏保持简洁。

`knowledgeTopics.ts` 优先采用 HR 指定的标准板块；历史内容根据条款标题匹配主题，无法匹配时归入综合制度。主题关联用于检索，不代表法律效力或政策之间的引用关系。

同名政策按来源、版本、适用地区、生效区间、发布日期和审核状态汇集。跨页正文保留原文顺序和各自出处。不明确的“手册资料”等标题不自动合并，以免把不同政策拼接在一起；HR 可在编辑内容中完善标题并指定板块。

此次调整只改变展示和检索组织方式，不删除知识条目、不修改原文或重新索引向量。原有制度问答继续使用原知识内容，租户与角色授权沿用现有接口。

验证：两个前端生产构建；`node scripts/test-knowledge-explorer.cjs` 检查分类、跨页汇集与版本隔离，并通过真实浏览器检查图谱、阅读、检索、移动端嵌入、助手入口和 HR 维护权限。验收不写入业务数据。
