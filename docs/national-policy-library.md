# 全国员工政策资料库补充（2026-09-11）

本次新增 50 份全国政策文件正文，原有 16 条国家/地方政策保留，合计 66 条；公司制度 152 条和参考资料 460 条未修改。数量是已收录文档/条目数，不是全国法律总数，也不是所有地区和行业政策已穷尽的声明。

覆盖劳动合同、考勤休假、薪酬税务、社保公积金、退休、劳动保护、争议处理、职业发展、档案及电子报销。国家政策与公司制度仍分开，均沿用原有放射式图谱和绿色主题。主题连线表示分类关系，不表示法律授权或替代关系。

## 来源和版本

来源目录：`n8nwork/knowledge-files/national-policy-catalog.json`。仅采用政府官网、国家行政法规库、最高人民法院等官方原文及官方转载。全国法规不能因为转载网站位于北京、上海而变成地方制度。

保留原始法律版本日期，不统一改写成“2026 版”。2026 年住房公积金条例标为待生效，2019 版有效至 2026-09-19。扣除标准、社保、退休等法规存在配套规则时在正文末注明；部分官方图片附表、办事附件保留原文入口，不能声称已转录所有附表或据此直接计算个人待遇。

## 更新流程

1. `python scripts/fetch-national-policy-library.py --refresh`：逐一复查目录中的官网正文，遵循 robots 与访问限制，保存来源快照及 SHA256。默认不加 `--refresh` 复用已成功快照。
2. 人工核对变化的正文、生效日期、失效关系、附件和条文完整性，更新目录内的 reviewedSha256。快照变化不会自动获得批准。
3. `python scripts/prepare-national-policy-library.py`：校验条文连续性、原文哈希、版本说明，生成导入计划。
4. `node scripts/import-national-policy-library.cjs`：预览；加 `--apply` 才实际写入。导入按标题、官网 URL、来源前缀幂等匹配，校验其他内容未变化。
5. `node scripts/test-national-policy-library.cjs --probe`：验证员工知识库可见性、版本边界和政策问答来源。

网站原文变化不代表自动改变公司的福利承诺。企业年金仍由已核实的企业资料确认，不能根据国家条例或搜索无结果推断公司已设立/未设立。

现有定时栏目爬虫继续按其配置运行；本批 50 份目录资料采用上述显式复查流程，未冒充已接入定时全网扫描。更新气泡分别展示知识库实际收录总量和该爬虫的候选审核数量。
