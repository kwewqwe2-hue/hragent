# 报销板块官网核验 · 2026-09-11

核验前，国家“差旅与报销”板块仅有财会〔2020〕6号。问题是后续配套文件缺失，不能仅因发文年份为2020年便认定该文失效。本次未检索到其整体废止依据，保留原正文、原日期，在开头增加本次核验及后续文件说明。

新增六份资料，均在国家图谱“差旅与报销”中阅读：

- 财会〔2024〕11号《会计信息化工作规范》，包含正式PDF附件全文50条，2025年1月1日起施行。
- 财会〔2025〕9号电子凭证会计数据标准推广通知，2025年5月9日印发。
- 铁路客运电子发票公告2024年第8号，2024年11月1日起施行；官网标注全文有效。
- 民航旅客运输电子发票公告2024年第9号，2024年12月1日起施行；官网标注全文有效。
- 财会〔2026〕9号《财务共享服务》正式指引，2026年6月23日印发，供相关单位参照执行，不是此前征求意见稿。
- 2026年电子凭证会计数据标准应用验证系统配套指南，属于技术操作资料，不是员工报销待遇政策。

最后两项未单独规定法律生效日，数据库不虚构生效日期。票据纸电过渡条款按乘车/乘机日期区分，不能把2025年9月30日前情形直接套用到2026年行程。国家凭证及系统管理要求不替代公司的住宿、交通、餐补额度与审批权限；本次未修改公司记录。

来源清单：`n8nwork/knowledge-files/reimbursement-policy-catalog.json`。重复核验命令：`python -X utf8 scripts/fetch-reimbursement-policies.py --refresh`。原文快照及校验哈希在 `.artifacts/reimbursement-review/sources/`；修改前快照、计划、执行ID和修改后快照分别为该目录上层的 `before.json`、`plan.json`、`applied.json`、`after.json`。

采集遵守官网 robots。财政部会计司的 robots 跳转到财政部明确的“页面不存在或已删除”页，按核对后的缺失规则处理；其他重定向或403不采用此例外。PDF由官网通知中的实际附件链接获取。

自动采集补充财政部会计司政策发布栏目，以及报销、电子凭证、电子发票、电子客票、行程单、财务共享、会计信息化主题；征求意见稿不作为正式政策发现结果。保持原有定时机制、同站点与数量上限，发现内容仍进入核验队列。税务总局动态目录没有直接可读的政策列表，本次采用官网法规库精确文件爬取，不声称已完成税务历史库全量或实时发现。

这是一轮针对报销凭证与财务共享的官网核验，不代表“全部法规都改成2026年版本”。发布日期、印发日期、生效日期仍需分别核对。
