# Agent AI 请假消息与审批

主管、HR 和员工在 Agent AI 顶部的“请假审批／请假审核动态”中查看请假消息。新待办和员工审核进度变化会显示浮动提醒，点击后打开审批弹窗，无需离开对话页面。

## 办理流程

1. 员工确认提交请假申请，主管收到待审批提醒。
2. 主管打开弹窗，查看员工、假种、起止日期、天数、申请说明及辅助资料；病假可以下载原始材料。点击通过或驳回，填写意见后确认。
3. 主管通过后进入 HR 审核阶段，HR 收到待办，员工看到“主管已通过，等待 HR 审核”。主管驳回则结束申请，并向员工显示意见。
4. HR 查看主管意见及相关资料，填写审核意见并确认通过或驳回。通过时更新余额和日历，驳回时保留原余额。
5. 员工在自己的 Agent AI 收到结果提醒，打开弹窗查看状态及主管、HR 的意见。

没有可用直属主管时沿用原有 HR 接管流程。网页、工作台和钉钉主管审批入口统一保留 HR 审核阶段；原集成方法名 `managerReviewAndAutoRecord` 为兼容接口保留。

## 同步与操作

打开 Agent AI 后每 5 秒读取本人记录与当前角色的待办，恢复窗口焦点时立即同步。关闭网页期间产生的更新会在下次打开时显示。已读标记按账号、员工档案、企业和角色隔离，刷新页面后保留；本地只保存状态与时间戳。

审批通过和驳回均需填写意见并确认，提交期间禁用重复操作。请求失败保留意见供重试；其他审核人员已处理时移除过期待办并提示。列表及审批接口沿用后端权限校验，主管处理本人下属，HR 处理本企业待办，排除本人审批。

后端在审批事务内锁定申请记录，HR 扣减时锁定对应假期余额，防止重复处理同一申请或并发扣减覆盖。集成回调在首次读取申请时即取得相同的申请锁。

## 验证入口

- `LeaveApprovalFlowTest`：两阶段审批、两种驳回、角色与企业隔离、自审批拦截、余额不足、重复操作与旧集成入口。
- `LeaveMedicalServiceTest`：病假材料及主管审批后进入 HR 阶段。
- `node scripts/test-agent-approvals.cjs`：运行构建后的真实 Vue 页面，以合成接口验证主管 → HR → 员工、失败重试、过期待办、原始材料下载、已读保持和手机布局。

浏览器测试使用独立接口响应，不创建业务申请。截图保存在 `.artifacts/agent-approvals`。
