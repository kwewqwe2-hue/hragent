# 员工回复体验

`EmployeeReplyStyle` 在业务完成路由、计算和生成操作按钮后调整回复表达，通过响应展示层统一覆盖聊天和附件回复。制度详情、日期数字、审批状态及按钮操作不变。模型提示词也采用温柔、轻快、适度可爱的表达；紧急支持及严肃申诉保持清楚平稳。

`TypewriterReply.vue` 只对当前对话新收到的回复逐字展示，完整正文立即保存到聊天记录。渲染内容先经过原有 Markdown 和 DOMPurify，再逐步显示文本节点，避免截断 HTML。最长约 7 秒，可立即显示；操作按钮及制度详情在正文显示完整后出现。切换对话、发送下一条消息、减少动态效果偏好及隐藏页面都会结束或跳过渐显。紧急支持类回复不延迟显示。

测试：`EmployeeReplyStyleTest` 验证事实和业务操作保持不变；`scripts/test-typewriter.cjs` 验证渐显、跳过、历史记录、减少动态效果及卸载清理；`scripts/test-care-progress.cjs` 验证实际 API 的温柔建议和实时进度查询，不创建员工申请。
