# HRAgent V1 新手学习路线

这份项目先别急着“全部看懂”。你可以按下面顺序学习，每一步只理解一个概念。

## 1. 这个系统由什么组成

```text
浏览器里的 Vue 页面
        ↓ 调接口
Spring Boot 后端
        ↓ 读写数据
MySQL 数据库

Spring Boot 后端
        ↓ 保存登录 token
Redis

Spring Boot 后端
        ↓ 调用大模型
DeepSeek API
```

## 2. SaaS 的关键是什么

SaaS 的核心不是页面漂亮，而是多个客户能共用一套系统，同时数据互相隔离。

这个 Demo 暂时只有一家“示例科技有限公司”，但后端实体里都保留了 `tenantId` 字段。以后支持多公司时，每个公司就是一个 tenant。

## 3. 登录发生了什么

1. 前端 `LoginView.vue` 把用户名和密码发给 `/api/auth/login`。
2. 后端 `AuthController` 接收请求。
3. `AuthService` 校验密码，生成 token。
4. token 存进 Redis，同时返回给前端。
5. 前端以后每次请求都在请求头里带上：

```text
Authorization: Bearer 你的token
```

## 4. 请假流程怎么走

1. 员工张三登录。
2. 在“我的请假”里提交年假、病假、事假或婚假。
3. 后端先查假期余额。
4. 后端调用智能体，生成辅助判断和依据。
5. 申请进入“待主管审批”。
6. 主管李四登录，在“主管审批”里通过或驳回。
7. 如果主管通过，申请进入“待 HR 备案”。
8. HR 王HR登录，在“HR 备案”里通过或驳回。
9. HR 备案通过时，系统扣减假期余额。

## 5. DeepSeek 在哪里接入

代码位置：

```text
backend/src/main/java/com/hragent/hragentv1/service/DeepSeekClient.java
backend/src/main/java/com/hragent/hragentv1/service/AssistantService.java
```

如果 `.env` 里没有 `DEEPSEEK_API_KEY`，系统会使用模拟回复，方便你先跑通流程。

## 7. 你以后可以怎么扩展

- 多公司注册：增加租户注册、公司创建、成员邀请。
- 更复杂审批：增加审批流表，例如主管、部门负责人、HR 多级审批。
- 员工导入：现在已经支持 Excel/CSV 导入员工和余额，下一步可以增加导入模板下载、字段映射、失败行导出。
- 政策采集：从官方渠道定期采集政策并标记审核状态。
- 钉钉/飞书接入：把登录、员工信息、审批消息接到真实平台。
- 权限系统：从固定角色扩展为 RBAC 权限点。

## 8. 新增 SaaS 地基怎么理解

### 组织配置

部门和岗位是员工主数据的基础字典。真实系统通常不会让导入文件随便创建部门，因为一个错别字就会把数据弄脏。

### 员工数据

员工数据相当于 HR SaaS 的主数据中心。请假、审批、余额、接口同步，最后都会围绕员工工号 `employeeNo` 运转。

### 数据导入

导入中心采用“先预览，再确认”的方式。预览阶段只校验文件，确认导入阶段才写数据库。这样做是为了防止一次错误表格直接污染系统。

### 接口中心

接口中心负责让外部系统访问 HRAgent。API Key 是外部系统的凭证，调用日志是排查问题和审计的依据。
