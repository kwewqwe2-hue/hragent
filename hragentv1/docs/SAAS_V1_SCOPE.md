# HRAgent SaaS V1 范围

更新时间：2026-07-13

## 产品定位

HRAgent V1 是一个多空间请假 SaaS Demo，并为后续 n8n 智能体提供账号、权限、员工数据、假期余额、知识库和工具接口。

第一版不做招聘、薪酬、绩效、报销、排班打卡、社保公积金、在线支付和真实插件市场。

## 身份模型

- 平台账号：全局登录身份，拥有不可枚举的公开用户 ID。
- 企业空间：公司或团体的数据边界，拥有空间码。
- 空间成员：账号与空间之间的关系，记录角色和加入状态。
- 员工档案：企业内的工号、部门、岗位、主管和假期数据。

一个账号可以加入多个空间，在不同空间拥有不同角色。

## 空间成员状态

- `PENDING`：已申请，等待空间管理员审核。
- `PENDING_PROFILE`：审核通过，等待管理员导入员工档案。
- `ACTIVE`：员工档案已绑定，可以使用空间业务。
- `REJECTED`：加入申请被拒绝。
- `LEFT`：已离开空间。
- `DISABLED`：被空间管理员停用。

## 角色边界

### 员工

- 查看自己的档案、假期余额、申请和消息。
- 查看假期制度、申请标准、知识库和企业通讯录。
- 使用智能体。
- 创建仅能访问本人数据的个人平台 API Key 和智能体 API Key。

### 主管

- 拥有员工全部能力。
- 查看全公司基础通讯录。
- 查看直属团队业务数据、团队日历和待审批申请。
- 不能查看非直属员工的请假原因、附件和假期余额。

### 空间管理员

- 原 Demo 中的 HR 角色。
- 审核加入申请、管理成员角色、组织和员工档案。
- 通过 CSV/XLSX 导入 `userId`、员工、主管关系和假期余额。
- 查看空间内全部请假记录并完成管理员备案。
- 管理知识库、权限、配置和空间操作日志。
- 不能查看密码、API Key 明文等秘密信息。

### 平台管理员

- 查看空间创建者、成员数、AI/API 调用次数和运行状态。
- 不查看企业员工档案、请假原因、知识库正文、审批意见和对话正文。

## 加入和建档流程

1. 用户注册平台账号。
2. 用户输入空间码并提交加入申请。
3. 空间管理员同意或拒绝。
4. 同意后成员进入 `PENDING_PROFILE`。
5. 管理员在员工导入表填写公开 `userId`、工号、角色和组织信息。
6. 导入成功后账号与员工档案绑定，成员进入 `ACTIVE`。
7. 未完成建档前，系统不显示 0 天余额，而是明确提示尚未绑定员工档案。

## 请假流程

员工提交 -> 直属主管审批 -> 空间管理员备案 -> 扣减余额并通知员工。

没有有效直属主管时，申请转交空间管理员。员工可在主管处理前撤回，后续版本增加退回、转交和委托。

## API 方向

- 个人平台 API：结构化读取本人档案、余额、申请和同步状态。
- 个人智能体 API：自然语言调用同一个 HRAgent 智能体。
- 企业集成 API：第一版保留为 HRAgent 与 n8n 的内部工具接口，后续按需开放给空间管理员。

API Key 必须绑定账号、空间、权限范围、到期时间和调用限制。权限在每次请求时动态检查，成员角色变化或停用后旧 Key 立即失去对应权限。

## 实施顺序

1. 全局账号、空间、成员、加入申请和角色底座。
2. 员工导入与注册账号绑定。
3. 员工、主管、空间管理员和平台管理员页面。
4. 通讯录、待办、通知和员工年度请假日历。
5. 个人平台 API 和个人智能体 API。
6. n8n 智能体与飞书接入。
