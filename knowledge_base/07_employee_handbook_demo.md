# 员工手册示例

本文件为员工手册 Demo 样例。

入职流程：

1. 员工提交身份证明、银行卡、学历证明等入职材料。
2. HR核验材料并创建员工档案。
3. 员工签署劳动合同、保密协议及相关制度确认文件。
4. 系统开通员工账号、考勤权限、薪酬档案。
5. 员工完成入职培训。

在职服务：

- 员工可咨询制度、假期、社保公积金、证明开具等问题。
- 员工可申请在职证明、收入证明、培训证明等文件。
- 员工可查询本人假期余额、社保公积金状态和工资条示例。

离职流程：

1. 员工提交离职申请或确认离职原因。
2. 主管和HR进行审批或沟通。
3. 员工完成工作交接和资产归还。
4. HR处理薪资结算、社保公积金、档案归档。
5. 根据流程开具离职证明。

转人工情形：

- 投诉
- 劳动争议
- 薪酬异议
- 绩效争议
- 员工情绪风险
- 政策或制度冲突
